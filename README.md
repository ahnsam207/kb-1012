# 두더지 잡기 게임

Streamlit으로 만든 3×3 두더지 잡기 게임입니다. `hole.png`로 빈 구멍 8개를, `img.png`로 두더지 1마리를 표시합니다. 두더지를 클릭하면 잡았다는 메시지가 나오고, 두더지는 직전과 다른 칸으로 이동합니다. 빈 구멍을 클릭하면 두더지 위치는 바뀌지 않습니다.

## 실행 방법

1. 의존성을 설치합니다.

   ```
   pip install -r requirements.txt
   ```

2. 앱을 실행합니다.

   ```
   streamlit run streamlit_app.py
   ```
